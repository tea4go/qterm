### 1.2 主题管理器

```rust
// src/theme/mod.rs
pub struct AppTheme {
    pub mode: ThemeMode,           // Light / Dark / Auto
    pub system: SystemTheme,
    pub terminal: TerminalTheme,
    pub extra: ExtraTheme,
}

pub enum ThemeMode { Light, Dark, Auto }
```

- `AppTheme::dark()` / `AppTheme::light()` 构造函数
- `set_mode()` 切换时重建所有子系统
- 配置文件记录当前 mode

### 1.3 全局应用 SystemTheme

- `app.rs`: 用 `system.app_content_term_bg_color` 替代硬编码 `self.theme.background`
- Tab 栏: 用 `system` 的分割线/背景色
- SSH 对话框: 用 `dialog_*` 色值
- 状态栏（Phase 2 建后应用）

### 1.4 修改文件清单

| 文件 | 操作 |
|------|------|
| `src/theme.rs` | 删除，拆分为 mod.rs / system.rs / terminal.rs / extra.rs |
| `src/app.rs` | 适配新 AppTheme 结构 |
| `src/config.rs` | 添加 theme_mode 字段 |

## Phase 3: 核心交互

**状态: [ ] 未开始**

**目标:** 实现复制/粘贴、鼠标文本选择、右键菜单、字体缩放。

### 3.1 鼠标文本选择

对齐文档 §11.2：

- 左键拖拽: 选择文本（需在 Terminal 中维护 selection state）
- 双击: 选中单词（按空格分隔符）
- 三击: 选中整行
- 选中文本高亮显示（selection_bg 色）
- Terminal 结构新增 `selection: Option<(usize,usize,usize,usize)>` (start_row, start_col, end_row, end_col)

### 3.2 复制粘贴

对齐文档 §11.1 / §13.1：

- Ctrl+C（有选中）: 复制选中文本到剪贴板
- Ctrl+C（无选中）: 发送 \x03 (SIGINT)
- Ctrl+V: 粘贴剪贴板内容到终端
- Ctrl+Shift+C: 强制复制
- Ctrl+Shift+V: 强制粘贴
- 双击选中后自动复制（可配置）

### 3.3 右键上下文菜单

对齐文档 §12.1 终端右键菜单：

## Phase 4: 连接管理系统

**状态: [ ] 未开始**

**目标:** 实现连接的 CRUD、分组管理、持久化存储，替换当前临时 SSH 对话框。

### 4.1 连接数据结构

对齐文档 §9.1：

```rust
struct Connection {
    conn_id: String,        // UUID
    name: String,           // 显示名称
    conn_type: ConnType,    // Normal / Local
    addr: String,           // 主机地址
    port: u16,              // 端口
    username: String,
    password: String,       // 加密存储（Phase 4.5）
    auth_model: AuthModel,  // Password / PrivateKey
    pri_key: String,        // 私钥路径
    group_id: String,       // 所属分组
    description: String,
    tab_type: TabType,      // 颜色标识
    local_path: String,     // SFTP 本地默认路径
    remote_path: String,    // SFTP 远程默认路径
}

enum ConnType { Normal, Local }
enum AuthModel { Password, PrivateKey }
```

### 4.2 分组管理

```rust
struct ConnGroup {
    group_id: String,
    group_name: String,
    parent_id: Option<String>,  // 支持嵌套
    sort_order: u32,
}
```
